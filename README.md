# 🚀 Outreach — Automated Cold Job Outreach & Follow-up Pipeline

An end-to-end engine for high-volume, personalized cold job outreach: discover
companies, enrich their contacts, generate tailored cover letters, send them,
and run automatic in-thread follow-ups — all driven from a simple **web control
panel** or the command line.

## Get started

The project lives in [`job-outreach-pipeline/`](job-outreach-pipeline/).

```powershell
cd job-outreach-pipeline
# One-click: double-click start_ui.bat, or:
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Then open **http://127.0.0.1:5000** to run the whole pipeline from your browser.

See [`job-outreach-pipeline/README.md`](job-outreach-pipeline/README.md) for the
full setup guide, credentials, and CLI commands.
